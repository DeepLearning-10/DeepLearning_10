## 멘티 결과에서 발견한 문제

1. 압력 IQR 이상치 행을 C라인에서 3행 삭제했다. - 완전 중복 제거 후 C라인은 60행이었지만, 멘티 결과에서는 57행이었다. - 이상값을 행째로 삭제하면 데이터가 줄고 라인별 데이터 균형이 깨지며, 이후의 이상치 재탐지에도 필요한 정보를 잃게 된다.

2. 완전히 같은 행만 중복으로 제거했다. - 검사일시·생산라인·설비번호가 같은 기록이 2쌍 남아 있었고, 온도는 최대 0.03도 정도 차이 났다. - 컴퓨터는 다른 행으로 인식하지만 현실에서는 같은 설비를 같은 시각에 중복 기록한 것이므로, 그대로 두면 특정 설비와 라인의 평균이 왜곡될 수 있다.

3. 전체 기준으로 온도 이상치를 판단했다. - 표 전체 z-score 기준에서는 이상치가 0건이었지만, 생산라인별 z-score 기준에서는 5건이 검출되었다. - 라인별 온도 수준이 다른데 전체 평균으로만 판단하면 C라인의 낮은 온도나 A라인의 높은 온도처럼 라인 안에서는 비정상인 값을 놓친다.

4. 결측 온도를 전체 평균으로 채웠다. - A라인 온도 평균은 이상값 포함 시 73.35도, 이상값 제외 시 72.05도로 1.30도 차이 났다. 또한 A라인 결측 기록은 멘티 정규화 결과에서 약 0.540으로 기록되었지만, 라인 기준으로 처리하면 약 0.061 수준이 된다. - 다른 라인의 높은 온도가 섞인 전체 평균으로 채우면 A라인의 정상 범위와 맞지 않는 값이 들어간다.

5. 압력 이상치를 한 번만 처리하고 끝냈다. - C라인 압력 표준편차는 1차 처리 전 약 1.253에서 1차 후 약 0.232로 줄었고, 2차에서 새 이상값 2건이 검출되었다. 3차에서야 0건이 되었다. - 큰 이상값이 표준편차를 부풀리면 조금 작은 이상값이 처음에는 숨을 수 있으므로, 한 번만 처리하면 이상값을 놓친다.

## 고치는 과정에서 내가 조심한 것

1. 원본 데이터를 바로 멘티 결과로 덮어쓰지 않고, 완전 중복 제거와 논리적 중복 제거를 거친 작업본을 만들어 재처리했다. 멘티 결과는 이미 결측 처리와 행 삭제가 끝나 있어, 왜 문제가 생겼는지 검증하기 위한 원본 상태가 부족하기 때문이다.

2. 온도 결측을 채우기 전에 생산라인별 이상값을 먼저 탐지했다. 이상값이 포함된 평균을 사용하면 결측값에도 왜곡된 값이 들어가므로, 이상값을 제외한 라인 평균으로 온도를 채웠다. 압력과 진동은 이상값 영향이 작은 중앙값을 사용했다.

3. 압력 이상치는 값을 중앙값으로 바꾼 뒤 평균·표준편차·z-score를 다시 계산했다. 값이 바뀌면 기준 통계도 달라지므로, 이전 통계를 그대로 사용하면 안 된다.

4. 정규화 기준은 전체 데이터가 아니라 학습 데이터에서만 만들었다. 테스트 데이터의 최솟값·최댓값을 미리 사용하면 테스트 정보를 학습 전에 본 데이터 누수가 발생하기 때문이다.

## 판단이 필요했던 지점

배치2에서 배치1에 없던 생산라인은 기존 모델 입력에서 제외하고 별도 데이터로 분리하기로 했다. 기존 라인코드(A=0, B=1, C=2)가 붙지 않고, 기존 학습 기준으로 정규화하면 값이 크게 0~1 범위를 벗어날 수 있기 때문이다. 해당 라인의 데이터가 충분히 쌓이면 별도 기준을 만들거나 새 라인을 포함해 모델을 다시 학습해야 한다.

## 멘티에게 전할 한 가지

다음에 같은 데이터를 받으면 가장 먼저 결측치·중복 기록·물리적으로 불가능한 값·라인별 분포를 확인해야 한다. 특히 전체 평균만 보지 말고 생산라인처럼 데이터가 만들어진 조건별로 나누어 이상치를 확인한 뒤, 그 기준으로 결측 처리와 정규화를 진행해야 한다.

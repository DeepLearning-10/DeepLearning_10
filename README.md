# 데이터분석 실습 기록

수업 과정에서 진행한 실습 코드와 Git 커밋 이력을 관리하는 저장소

## 실습 시작 전

1. 오늘 날짜 폴더가 있는지 확인
2. 없으면 `YYYYMMDD` 형식으로 생성
3. 해당 날짜 폴더 안에 실습 이름 폴더를 생성
4. 실습 코드는 기본적으로 `s1.py`부터 작성한다.
5. 실습이 끝나거나 의미 있는 작업 단위가 끝날 때 커밋

## 디렉터리 규칙

```text
수업자료/
└── YYYYMMDD/
    └── 실습이름/
        ├── s1.py
        ├── s2.py
        └── ...
